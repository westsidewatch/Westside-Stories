# Westside Stories

> Write the vision, and make it plain.  
> *Habakkuk 2:2*

Westside Stories is a free and open-source macOS subtitle application created for sermons, Bible studies, testimonies, and ministry videos.

**Developed for**  
神召會活水堂西區教會  
P.A.O.C. Living Water Assembly West

Part of the **Westside Watch** ministry.

## Features

- Local MLX Whisper transcription
- SRT generation
- Burn subtitles into MP4
- Traditional Chinese + English interface
- Local processing
- macOS Apple Silicon workflow
